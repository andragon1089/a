# NZ & China Essay Statistics Flashcards

A self-contained, mobile-friendly flashcard deck for memorising the statistics and dates from the essay.

## Use locally
Open `index.html` in any modern browser. No installation or internet connection is required. Progress is saved in that browser on that device.

## Publish with GitHub Pages
1. Create a new **public** GitHub repository (for example, `nz-china-flashcards`).
2. Upload `index.html` to the repository's root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide a public website URL after deployment.

The cards preserve the figures and wording from the supplied essay; check any figures against your class materials before the exam.
